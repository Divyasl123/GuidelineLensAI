
# GuidelineLens AI

## Self-Improving Brand Governance & Guideline Intelligence Platform

**Detect Inconsistencies. Understand the Rules. Improve Brand Trust.**

---

## About the Project

GuidelineLens AI is a web-based brand governance platform designed to review marketing content before publication. It checks submitted content against built-in rules and saved brand guidelines, identifies potential violations, explains the issues and suggests corrections.

The platform also allows human reviewers to approve or reject findings and maintains an audit history of review decisions.

## Key Features

- Content Review and Analysis
- Brand Guideline Management
- Automated Rule-Based Detection
- High, Medium and Low Severity Classification
- Suggested Content Corrections
- Human Approval and Rejection
- Audit History and Decision Tracking
- Guideline Intelligence

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Tools:** Visual Studio Code, GitHub

## How It Works

1. Submit content for review.
2. Analyze content against brand guidelines.
3. Identify potential violations.
4. View explanations and suggested corrections.
5. Approve or reject findings.
6. Track decisions through Audit History.

## Installation and Execution

1. Clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.
